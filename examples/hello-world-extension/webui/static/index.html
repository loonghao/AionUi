/ext/hello-world/hello-world/index.html

📖 How to Use WebUI Extensions

To add WebUI capabilities to your extension, define webui in aion-extension.json: 

{
  "contributes": {
    "webui": {
      "apiRoutes": [{
        "path": "/hello",
        "entryPoint": "webui/api/hello.js",
        "auth": false
      }],
      "staticAssets": [{
        "urlPrefix": "/hello-world",
        "directory": "webui/static"
      }]
    }
  }
}

API entry points export an Express router. Static assets are served directly. All routes are sandboxed under /api/ext/ and /ext/ prefixes.
